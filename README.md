# 🌍 Air Quality Data Cleaning & Missing Value Analysis

A Python project that demonstrates **data cleaning and preprocessing** on the Air Quality UCI dataset. The project focuses on identifying, visualizing, and handling missing values using Pandas, NumPy, Matplotlib, and Seaborn.

## 🚀 Features
- Load and explore the dataset
- Replace sentinel values (`-200`) with `NaN`
- Analyze missing values
- Visualize missing data using heatmaps and bar charts
- Drop columns with excessive missing values
- Apply mean and median imputation
- Verify the cleaned dataset

## 🛠️ Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Files
- `airquality.ipynb` – Main notebook
- `AirQualityUCI.csv` – Dataset

## 📈 Outcome
This project demonstrates a complete data preprocessing pipeline and prepares the dataset for further analysis and machine learning.
